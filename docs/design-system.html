02 · Signature

하이라이터 + 캘린더 도트

텍스트 뒤를 형광펜처럼 칠하는 4색 시스템 — 커뮤니티 탭(일정/세미나/모임) 전용입니다. Recipe / Q&A / 프로필 / 설정 등 다른 탭의 리스트 타이틀에는 절대 적용하지 않습니다. 카테고리 분류 기능이 없는 곳에서 장식 목적으로 쓰면 시그니처가 무너집니다.

⚠ Scope rule
노랑 / 파랑 / 그린 하이라이터는 커뮤니티 탭 내부의 리스트 타이틀 + 캘린더 라벨에서만 사용. 그 외 탭은 평문(fg-strong) 또는 칩 / 뱃지로 카테고리를 표시합니다. hl-red(긴급)는 전역 사용 가능하지만 한 화면 1회.

12 · Guide

Do & Don't

기능 명세서를 받았을 때 가장 먼저 확인할 체크리스트입니다.

Do

  • 흰 배경 + 검정 + 빨강 1회 — 이 비율 절대 유지
  • 영문 ALL CAPS에 tracking 0.16em
  • 로고는 Galmuri11, 그 외 모두 서울남산체
  • 카테고리 표시는 하이라이터 4색 매핑 고정 — 커뮤니티 탭에서만
  • 커뮤니티 외 탭(Recipe / Q&A 등)의 리스트 타이틀은 평문(fg-strong)
  • 카드는 flat — 그림자 대신 1px 보더
  • Primary CTA는 페이지당 1개, 풀폭 빨강
  • Floating label 입력 패턴 — 모든 폼 동일
  • 모바일 히트 영역 44×44 이상

Don't

  • 빨강 한 화면에 3회 이상 사용
  • 본문/숫자에 Galmuri11 사용
  • 카드에 그림자(elevation) 추가
  • 둥근 모서리 12px 초과 (FAB/캘린더일 제외)
  • 한 화면 폰트 사이즈 4단계 초과
  • 영문 ALL CAPS에 tracking 미적용
  • 그라데이션 배경
  • 이모지를 의미 전달 수단으로 사용 (아이콘 사용)
  • 커뮤니티 탭 밖에서 노랑/파랑/그린 하이라이터 사용 — 의미가 무너짐
  • 카테고리 분류가 없는 리스트 타이틀에 하이라이터 장식 적용
