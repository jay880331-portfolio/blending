- [당근 App Store](https://apps.apple.com/kr/app/%EB%8B%B9%EA%B7%BC/id1018769995)처럼 생활 장면을 한 장의 메시지로 전달한다.
- [Google Play 규칙](https://support.google.com/googleplay/android-developer/answer/9866151?hl=ko)과 [Apple 스크린샷 규격](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/)에 맞춰 실제 사용자 데이터·캡처·CTA를 쓰지 않는다.
