| --------------------------- | ----------------- | -------------------------------------------- |

## 순서·카피·alt text

| 순서 | 카피                                                                                          | Google Play 한국어 alt text                                  |
| ---- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 01   | 커피 커리어가<br>서로를 만나는 곳<br><small>경력을 기록하고, 사람과 기회를 발견하세요</small> | 밝은 배경의 픽셀 아트와 함께 BLENDING을 소개하는 이미지      |
| 02   | 경력과 작업을<br>한 장의 프로필로                                                             | 커피 프로필과 경력, 포트폴리오를 보여주는 BLENDING 홈 화면   |
| 03   | 가까운 커피인을<br>지도에서 발견하세요                                                        | 지도와 바리스타 카드로 주변 커피인을 찾는 BLENDING 지도 화면 |
| 04   | 놓치기 쉬운 일정을<br>한눈에 모아보세요                                                       | 2026년 7월 달력과 커피 일정을 보여주는 BLENDING 캘린더 화면  |
| 05   | 현장의 경험으로<br>장비를 고르세요                                                            | 현장 장비 리뷰 목록을 보여주는 BLENDING 파트너 화면          |
| 06   | 기록부터 연결까지<br>내 활동을 한곳에                                                         | 커피 프로필과 활동 메뉴를 보여주는 BLENDING 마이페이지 화면  |

02–06은 실제 앱 캡처를 베이스로 하며, 스토어 노출에 맞춘 촬영용 데이터를 캡처의 기존 화면 구조와 정렬에 맞춰 합성한다. 촬영용 데이터이며 실제 사용자 개인정보가 아님. 생성된 중간 화면은 `raw/`에, 최종 업로드 파일은 `final/`에 둔다.

리뷰관 썸네일은 실제 상업용 에스프레소 머신·그라인더·핸드드립 작업을 촬영한 Unsplash 사진을 사용한다. 재생성 시 해당 사진 다운로드를 위한 네트워크 연결이 필요하다.

이전 버전은 [`archive/v1/`](archive/v1/)과 [`archive/v2/`](archive/v2/)에 보관한다.
